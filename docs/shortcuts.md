# Codex 和终端快捷键

输入助手的“更多按键 ▾”打开分组列表，可上下滚动；点击条目只发送一次。打开列表、方向键移动选择、关闭列表都不发送远程输入。普通条目立即发送，Ctrl+C、Ctrl+D、Ctrl+Z 和双 Esc 先显示确认框，默认聚焦取消。网络、接管或观看代次变化会清除未确认操作。

以下用途依据已核对的 Codex CLI `0.166.0`，实际行为以部署者使用的 CLI 版本和自定义键位为准。项目不自动安装或升级 Codex。以下按 CLI 与终端默认键位说明，不套用桌面 App 或 IDE 的同名组合；自定义键位和当前焦点程序可能改变用途。先点选远程 Codex 终端，再操作输入助手。

共 39 个可发送条目，清单见[快捷键定义](../panel/public/shortcuts.js)。Ctrl+O 复制到远程剪贴板后，可用“取回文字”明确读取，再复制到本机。网页草稿仍由“粘贴文字”按钮发送，提交仍由独立 Enter 完成。

部分 xterm 会将 Shift+Enter 编码为普通 Enter，所以列表提供已验证的 Ctrl+J 换行。固定 Alt 编辑组合使用零间隔 ESC 前缀编码，兼容此 xterm 的 Meta 高位字符模式；它们用于终端输入，不作为其他桌面应用的 Alt 菜单快捷键。双 Esc 使用固定两键、80 毫秒间隔，不附加 Enter。

## 发送与恢复

所有条目复用现有输入接口：可用时走加密 DataChannel，否则走已认证 HTTPS。服务端只接受固定白名单，并用固定 argv 发送，不解析用户定义的组合、shell 命令或任意按键序列。输入仍互斥执行，不排队；断线、结果未知、超时和重连都不会重发已发送按键。

列表与确认操作都不持久化。打开列表时延后自动换流和窗口尺寸适配；关闭后恢复检查。隐藏页面、失去焦点、断线、接管、退出和折叠输入会关闭列表。老浏览器没有 Popover API 时使用同一列表的定位回退，支持方向键、Home/End、Tab 和 Esc，触控条目至少 44 像素。

快捷键说明依据 [OpenAI 官方 CLI 交互说明](https://learn.chatgpt.com/docs/developer-commands?surface=cli#interactive-shortcuts) 与 [CLI 外部编辑器说明](https://learn.chatgpt.com/docs/cli-customization#prompt-editor)，并核对上述特定 CLI 版本。原生验证使用隔离 Xvfb、xterm 与私有 tmux 捕获实际字节，不向工作中的 Codex 发送测试按键。

## 网页终端的程序翻页与回到实时

宽屏默认把终端标签、翻页和查找复制放在左侧栏，主工作区保留完整高度；窄屏显示顶部工具栏。可在“工具 → 界面布局”切换，选择仅对当前浏览器生效，详见[浏览器布局](browser-preferences.md#工具面板)。

“工具 → 程序鼠标”默认关闭，网页直接处理拖选和右键复制，不向程序上报鼠标点击、拖动或移动。开启后可使用 Codex 等终端程序内的鼠标操作；键盘输入不受该开关影响。偏好只保存在当前浏览器，所有网页终端共用，不改动桌面终端或程序配置；切换开关不重启终端、不发送输入。

普通本地回看不发送按键。明确开启“程序翻页”后，点击上翻/下翻分别发送一次 PageUp/PageDown。同时开启“程序鼠标”且程序支持 SGR 鼠标报告时，滚轮按程序的原生小步规则移动；关闭“程序鼠标”或程序不支持时，滚轮及触摸手势每 160 毫秒最多发送一次翻页按键。只打开或关闭程序翻页不发送按键。

“查找复制”的展开状态独立于翻页和画面状态。切换程序翻页、上翻/下翻和回到实时均保留工具条与关键词；主动收起、切换终端或离开终端视图时关闭。仅展开工具条不暂停终端输入；进入历史快照后暂停编辑，回到实时后恢复输入并保留工具条。接收和显示程序输出继续运行。

程序翻页开启时，点击上翻/下翻发送一次对应按键并显示程序画面，按钮不受快照边界限制。保留的关键词可按回车或点上一个/下一个，重新读取当前已加载内容进行本地查找；复制或下载也会读取当前内容，避免使用翻页前的旧快照。已冻结快照中的滚动、键盘翻页、查找和复制不发送程序输入；程序翻页关闭时，上翻/下翻只操作本地历史。切换开关会取消尚未完成的历史读取，迟到结果不会覆盖当前画面。

开启程序翻页，或实际向程序翻页后，点击“回到实时”发送一次 `Ctrl+End`（`ESC [ 1 ; 5 F`），保持原有程序翻页开关状态，可继续翻页；不会循环发送 PageDown、附加 Enter 或用 Esc 中断任务。先关闭程序翻页或打开本地查找快照，也保留返回入口。此标记只在当前终端页面内存保存，切换终端目标后清除；重连和网络恢复不自动发送。不可发送时明确提示，需连接恢复后再次点击。

当前 Codex 0.166.0 的自有历史视图将 `Ctrl+End` 映射为跳到最新输出，普通 End 属于编辑器行尾行为；对应 [JumpTarget 与滚动处理源码](https://github.com/openai/codex/blob/rust-v0.166.0/codex-rs/tui/src/transcript_view/input.rs)。其他程序或自定义键位的具体行为由该程序决定，本项目不修改 Codex 配置。
