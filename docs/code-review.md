## 已修复

| 级别 | 问题与触发条件 | 修复和验证 |
| --- | --- | --- |
| P2 | 登录状态启动时整文件读取；本地损坏或超大的 JSON 可超出预期资源范围，原实现也会跟随文件符号链接。 | `panel/auth.mjs` 使用文件描述符读取，最多 16 KiB，拒绝符号链接、非普通文件、非当前用户文件；非阻塞打开避免 FIFO 挂住启动。只恢复最近八条格式有效的记录，舍弃未知字段。超大文件、符号链接、目录、FIFO 均有真实临时文件回归。 |
| P2 | 固定登录状态临时路径直接写入；该路径若预先是符号链接，会覆盖链接目标。已在隔离临时目录复现。 | 写入前只清理当前用户拥有的普通旧临时文件，使用 `O_EXCL` / `O_NOFOLLOW` 创建 0600 文件，sync 后原子替换。针对链接目标不变、并发创建/撤销、恢复及权限检查均通过。风险涉及能修改本地状态目录的主体，不是远程认证绕过。 |
| P2 | 桌面/网页终端直连只在完整 DataChannel 消息到达后检查长度，缺少端口映射已有的 SCTP 重组前防护。认证 peer 可以先让协议栈积累碎片或元数据。 | 提取 `panel/rtc-sctp.mjs`，三个直连用途共用接收窗口、最多 32 个流、1,024 个重组碎片、2,048 个乱序记录、1,024 个重复记录的检查；单碎片还受至多 1 MiB 窗口限制。超限或授权失效只关闭相应 peer。已有边界回归及真实 UDP/DTLS/SCTP 传输检查通过。依赖内部接口仍绑定固定 werift 0.26.0，升级时需要复核。 |
| P2 | Firefox 从 iframe 打开移到顶部的历史工具，以及在历史中按 Ctrl+F，焦点会留在 iframe。 | 在所属浏览上下文中设置焦点；首次打开的焦点处理复用单个有界布局回调，关闭/重连取消。三引擎检查普通打开、Ctrl+F、关闭返回及手动复制框焦点。 |

Shift+←、Shift+→ 同时加入原生固定白名单和网页终端编码，使用固定 argv / CSI，保留单次发送、独立粘贴和 Enter。真实隔离 Xvfb/xterm/tmux 捕获的字节与预期一致。

## 已核对的边界

- 浏览器面板的 HTTP 和 WebSocket 均保留登录、Host 和 Origin 检查，写请求保留 CSRF、当前 viewer、异步操作后的控制权复查；没有放宽局域网的授权。
- 面板与 helper 继续回环监听，VNC 仍通过 0600 私有 Unix socket。ICE 接收前保留地址范围、认证 STUN 和队列限制，公网 IPv6 不改变登录要求。
- 连接恢复保持一个上游、有限输出缓存和输入不重放；不通过恢复重新发送提示、确认、按键或旧 TCP 数据。
- 终端使用固定槽位、目标 token 和焦点验证，用户文本不插入 shell 命令。历史按需读取和选区复制各有 64 KiB 上限。
- 端口映射维持四个映射、每映射八条连接、单次配对及有期限的恢复；自定义目标只接受 IP 字面值及端口，不执行用户 shell。
- 应用版本继续精确锁定，未新增应用持久日志、凭据缓存或磁盘队列。会话持久化使用一个 writer 和一个 dirty 标记，避免每次请求新增一个待写 Promise 链。
- 安装与恢复不静默升级应用依赖，也不修改用户 Codex 配置。工作目录、运行文件、浏览器测试环境和产物均在 Git 忽略范围。
