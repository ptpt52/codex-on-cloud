## 已核对的边界

- 浏览器面板的 HTTP 和 WebSocket 均保留登录、Host 和 Origin 检查，写请求保留 CSRF、当前 viewer、异步操作后的控制权复查；没有放宽局域网的授权。

- 应用版本继续精确锁定，未新增应用持久日志、凭据缓存或磁盘队列。会话持久化使用一个 writer 和一个 dirty 标记，避免每次请求新增一个待写 Promise 链。
- 安装与恢复不静默升级应用依赖，也不修改用户 Codex 配置。工作目录、运行文件、浏览器测试环境和产物均在 Git 忽略范围。
