# 统一 Bash 开发环境

系统终端和网页终端共享当前 Linux 用户的开发设置。后台服务仍使用部署时固定的运行时；显示、认证、私有 tmux 和工作区身份继续属于各自会话。

## 配置一次

在节点仓库中，以开发用户执行：

```sh
npm run shell:setup
```

此命令是显式的用户配置操作，普通部署、重连和故障恢复都不会自动执行。它创建 `~/.config/shell/dev-env.sh`，在 `~/.bashrc` 和 Bash 实际优先读取的登录文件开头加入加载块；登录文件按 `.bash_profile`、`.bash_login`、`.profile` 顺序选择。已有共享文件保留，重复执行不重复插入。原始启动文件保存在 `~/.config/shell/backups/` 的同名文件中；新创建的启动文件没有原始备份。

**继续整理原有设置**：将原来 `.profile`、`.bashrc` 中的开发 PATH、代理、编辑器、语言及 Go/Rust 等环境声明移入共享文件，并移除原位置的重复声明。命令不自动解析或搬移任意用户 shell 代码；留在原位置的设置仍会按原顺序执行，可能再次覆盖共享设置。保留 `.bashrc` 中的别名、函数、提示符和 nvm、pyenv 等交互工具初始化，并让它们位于加载块之后。登录 Bash 需要初始化这些工具时，保持登录文件加载 `.bashrc` 的原有逻辑。

共享文件兼容 `/bin/sh`，只处理环境设置，不运行任务或激活特定项目环境。PATH 从明确的系统基础路径开始，按需加入已安装工具的实际绝对路径，使新 shell 不再依赖后台启动时捕获的旧 PATH。不要在配置中使用 `$PWD` 或仓库相对路径。可参考 [模板](../desktop/dev-env.sh)；模板不会安装、切换或升级工具，nvm 等版本选择继续由用户配置决定。

环境加载顺序：

| 入口 | 初始化顺序 |
| --- | --- |
| 登录 Bash | 登录文件加载块 → 共享环境 → 原有登录初始化；若加载 `.bashrc`，继续其下方流程 |
| 系统交互 Bash | `.bashrc` 加载块 → 共享环境 → 用户交互设置与工具初始化 |
| 网页主／辅助终端 | 项目终端初始化 → `.bashrc` → 共享环境 → 用户交互设置与工具初始化 → 恢复会话身份 |

共享声明可能在登录时加载两次，须允许重复加载。模板直接重建基础 PATH，不使用会被子 shell 继承的“已加载”环境标记，避免配置更新后新终端仍跳过加载。网页终端不会额外执行登录文件或再次加载 `.bashrc`。

## 保留会话隔离

网页终端清除后台强制传入的 `LC_ALL`，随后尊重用户配置的 `LANG`、`LC_ALL` 等语言设置；`LANG` 为空时回退 `C.UTF-8`。项目辅助工具目录只在存在且尚未加入时追加到 PATH 末尾，不将后台完整 PATH 放回前面。

不要在共享开发配置中设置 `HOME`、`DISPLAY`、`WAYLAND_DISPLAY`、`XAUTHORITY`、桌面 `XDG_*`、`FONTCONFIG_FILE`、`TMUX*`、`WORKSPACE_DIR` 或 `TRANSFER_DIR`。网页终端会恢复原来的显示与 tmux／工作区身份；已存在的 XDG 路径和桌面会话总线同样保留。纯终端模式没有桌面会话总线时，仍允许用户 `.bashrc` 配置自己的总线。工作目录、终端类型和当前项目虚拟环境不要求与另一个终端相同。

配置位于固定的 `$HOME/.config/shell/`，不跟随虚拟桌面的 `XDG_CONFIG_HOME`。真实用户配置和代理凭据不加入 Git，也不打印到日志；仓库只保存无凭据模板。一个共享文件、最多四个固定名字的原始启动文件备份，每个最多 64 KiB，无快照队列或历史日志；加载块跳过超过 64 KiB 的共享文件。设置命令拒绝链接、非普通文件、其他用户文件及超限启动文件，修改前验证所有目标，写入使用同目录临时文件并清理。备份目录限当前用户访问，已有启动文件保留权限，新配置和备份为 0600。

## 更新与验收

修改项目的 `desktop/terminal.bashrc` 或共享环境后，新建终端立即读取；已有 tmux shell 和正在运行的程序保持原环境。无需重启 desktop／terminal 宿主，也无需重启 panel、manager 或 Tunnel。浏览器刷新和重连只附加已有 shell，不重新初始化或重放任务。空闲旧终端可由用户手动加载配置；不要向工作中的 Codex 或命令注入更新操作。

在新开的系统 Bash 和网页 Bash 中比较：

```sh
command -v node npm python3 go git codex
node --version
npm --version
python3 --version
```

只比较已安装的工具；纯终端模式不要求安装 Codex。代理等私有值在本机比较，不复制整份 `env` 到聊天或日志。核对工具选择与用户设置一致，原终端 PID 保留、重连未重复初始化；桌面模式另确认显示、Xauthority、XDG 路径仍属于虚拟桌面。

自动规格 `test/shell-environment.test.mjs` 使用真实 Bash、临时 HOME 和工具替身，覆盖配置保护、登录优先级、更新、语言及会话隔离；`test/terminal-shell.test.mjs` 使用真实隔离 tmux/Bash 检查主／辅助 shell 和已有任务保留。这些不代表真实 Codex 登录、生产浏览器交互或目标电脑的代理连通性。

回退时恢复备份中的启动文件；没有原始备份的新文件只移除本命令标识的加载块。已有共享配置保留供用户核对，回退不重启任务宿主。
