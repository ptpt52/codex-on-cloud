# 使用工作台

先通过自己配置的入口登录。账号密码在部署主机的 `secrets/credentials.txt`；固定网关的选择页使用单独的网关密码，见[节点切换](gateway.md)。

## 桌面与终端

- 桌面部署可在“桌面／网页终端”之间切换，连接到同一机器上的任务。纯终端部署只显示网页终端。
- 初始终端是 shell，按需手动运行 `codex` 或自己的程序。重新连接不会自动启动程序、提交提示词或重放审批。
- 标签能放下时平铺，放不下的项进入下拉列表；手机使用列表。支持新开、重命名、切换和明确确认后结束终端。
- 新开 shell 不会自动运行 Codex。默认最多 4 个终端，可通过 `MAX_TERMINALS` 配置为 1–8，见[配置参考](deployment-config.md#终端数量)。

关闭浏览器、切换节点或网络重连不结束任务。明确结束终端、停止任务宿主或重启主机，会影响其中运行的程序。

## 手机输入与剪贴板

“输入”打开文字助手：先核对目标终端，再点击“粘贴文字”。**粘贴不执行命令，Enter 单独提交**；终端粘贴使用 Ctrl+Shift+V。中文输入法组合期间不会自动发送。

“发送到远程”和“取回文字”分别操作。取回后先预览，再复制到自己的设备，不自动同步两端剪贴板。草稿按终端身份保留在当前标签页，不随账号同步到其他浏览器。

“更多按键”提供固定快捷键；中断和结束类动作需要确认。完整清单见[快捷键](shortcuts.md)。

## 查看与显示

- 桌面默认按宽度缩放，可切到适应窗口、原始比例或手动缩放。滚动画面与滚动远程程序分别选择。
- 网页终端支持选字复制、字号、宽度适配和历史阅读；工具中的浏览器偏好不会修改服务器终端启动配置。
- “快速切换待命”仅桌面部署可选，默认关闭；开启后增加内存和网络用量。
- 显示偏好保存在当前浏览器，共享服务器设置需要明确保存。范围见[浏览器偏好](browser-preferences.md)。

## 文件与设备

“文件中转”只访问配置工作目录下的 `transfer`，上传单文件最多 50 MiB。同名上传默认取消，可选择保留两份或确认替换；断线和结果未知不自动重传。HTTPS 与文件直连使用相同的权限和冲突规则。

“端口映射”通过本地助手配对，可让本机访问服务器 TCP 服务，也可授权服务器访问本地设备。每次配对有明确目标和权限，不在终端中自动执行命令。见[TCP 映射](forward.md)和[串口接入](serial.md)。

## 权限与连接

每套工作台面向一位管理员；临时账号仅有有限文件／设备访问权限。屏幕锁、临时账号和映射授权的具体范围见[访问权限](access.md)。

同一桌面由一个页面持有控制权，新页接管后旧页停止输入。断线或执行回复未知时，先核对结果再决定下一步；恢复连接不会补发操作。

“连接状态”显示当前直连或中转、宿主和文件服务就绪情况。需要从网页换机器时，使用“工具 → 切换入口节点”；该入口只在已接入[固定网关](gateway.md)的节点显示。
