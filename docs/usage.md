# 使用工作台

从自己配置的入口登录，节点账号密码在部署主机的私有 `secrets/credentials.txt`。登录页已有节点标识时，保留预填登录名，方便浏览器分别记住密码；中心 / CF 网关管理密码与节点密码不同，见[访问权限](access.md)。

## 桌面与终端

桌面部署可在“桌面 / 网页终端”之间切换，连接到同一机器的任务；纯终端部署只显示网页终端。初始 shell 不自动运行 Codex，按需输入 `codex` 或自己的程序。重新连接不会重新提交提示词或审批。

- 标签放得下时平铺，溢出的部分进入下拉列表；手机使用列表。
- 新开终端创建独立 shell；切换只改变查看 / 输入目标，不移动任务。
- 通过终端旁的操作菜单重命名或结束终端，电脑右键也可打开同一菜单；平板和手机点击菜单按钮。
- 结束终端需确认，会影响该终端前台任务；默认四个名额，可设为 1–8，见[配置参考](deployment-config.md#终端数量)。

关闭浏览器、切换入口节点或网络重连保留任务。明确结束终端、停止 / 重启任务宿主或重启主机会影响程序。

## 手机输入与剪贴板

打开文字输入助手，先核对目标终端，再点击“粘贴文字”。**粘贴不执行命令，Enter 单独提交**；图形终端粘贴使用 Ctrl+Shift+V。中文输入法组合期间不会自动发送。

“发送到远程”和“取回文字”分别操作；取回后先预览，再复制到自己的设备，不自动同步两端剪贴板。草稿按当前标签页、节点和终端身份保留，不同步到其他设备。

“更多按键”提供固定组合，中断和结束类动作需确认，见[快捷键](shortcuts.md)。断线或执行回复未知时先核对远端结果，恢复连接不会补发输入。

## 查看与显示

桌面默认按宽度缩放，可选择适应窗口、原始比例或手动缩放；本机滚动画面和滚动远程程序分别选择。网页终端提供选字复制、字号、宽度适配和历史阅读。

显示偏好保存在当前浏览器的网站源，同源节点共用；服务器桌面分辨率属于远端共享设置，需要明确操作。快速切换待命仅桌面部署可选，默认关闭，开启会增加资源用量。范围见[浏览器偏好](browser-preferences.md)。

## 文件与设备

“文件中转”访问节点工作区下的 `transfer` 共同目录。上传、同名替换、目录配额及直连规则见[文件说明](files.md)；结果未知时先刷新列表，不自动重传。

“端口映射”通过本地助手一次性配对：可让电脑访问服务器网络，也可授权服务器访问电脑可达的设备。每次授权固定目标，反向设备需在助手本地确认；不会在终端自动执行连接命令。见[TCP 映射](forward.md)和[串口接入](serial.md)。

## 控制权与访问权限

同一工作台由一个页面持有桌面 / 终端控制权，新页接管后旧页停止输入。开启屏幕锁后，刷新或重新接管需要再次解锁；锁屏不停止后台任务，也不自动撤销已配对的映射。

临时账号只开放指定的共享文件与反向设备功能，不能进入桌面或终端。完整权限见[屏幕锁与临时访问](access.md)。

## 在多个节点之间访问

| 入口 | 操作与影响 |
| --- | --- |
| Cloudflare 网关 | 工具中的“切换入口节点”或 `https://desk.example.com/__nodes/`；选择全局默认节点，后续访问使用新节点 |
| 自建中心 | 打开 `https://desk.example.com/` 查看在线节点，进入各自 `/node/<slug>/`；可分别收藏和打开，不改全局默认路由 |
| 独立域名 | 打开对应节点自己的域名 |

各节点账号、任务和文件分别管理。切换入口不迁移文件、不终止原任务，也不会把旧页面的写请求发给新节点。单节点部署不需要额外节点选择页。

“连接状态”按用途显示实际网络路径以及宿主 / 文件服务就绪情况，诊断与回退说明见[网络指南](lan.md)。
