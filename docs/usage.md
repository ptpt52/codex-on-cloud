# 使用工作台

从自己配置的入口登录，节点账号密码在部署主机的私有 `secrets/credentials.txt`。登录页已有节点标识时，保留预填登录名，方便浏览器分别记住密码；中心 / CF 网关管理密码与节点密码不同，见[访问权限](access.md)。

## 桌面与终端

桌面部署可在“桌面 / 网页终端”之间切换，连接到同一机器的任务；纯终端部署只显示网页终端。初始 shell 不自动运行 Codex，按需输入 `codex` 或自己的程序。重新连接不会重新提交提示词或审批。

- 标签放得下时平铺，溢出的部分进入下拉列表；手机使用列表。
- 新开终端创建独立 shell；切换只改变查看 / 输入目标，不移动任务。
- 通过终端旁的操作菜单重命名或结束终端，电脑右键也可打开同一菜单；平板和手机点击菜单按钮。
- 结束终端需确认，会影响该终端前台任务；默认四个名额，可设为 1–8，见[配置参考](deployment-config.md#终端数量)。

关闭浏览器、切换入口节点或网络重连保留任务。明确结束终端、停止 / 重启任务宿主或重启主机会影响程序。

桌面视图的宽屏侧栏也会列出已有终端。点击可激活该终端窗口，并把输入助手目标切到同一终端；不会新建任务。直接在桌面打字仍跟随实际窗口焦点，输入助手目标以面板中的选择为准。

## 手机输入与剪贴板

电脑桌面默认开启“工具 → 本机输入法直输中文”。点击远程窗口的输入位置，使用本机输入法选字，确认的文字会自动输入当前窗口；选字时的 Enter 不会提交命令，结束选字后再按 Enter 才发送。图形终端使用 Ctrl+Shift+V，普通应用使用 Ctrl+V；需要应用支持对应粘贴操作。这会更新远程文字剪贴板，不会自动读取本机或远程剪贴板。

中文输入期间会暂存后续按键以保持顺序，最多 64 项、文字合计 32 KiB；断线、失权或焦点变化时清理未发送部分，结果未知时先核对远端，不自动补发。点击关闭工具或输入面板后，键盘焦点回到桌面；按 Escape 关闭则回到对应入口按钮，选字期间的 Escape 交给输入法处理。状态刷新不会抢焦点。触屏设备继续使用输入助手，连接鼠标且浏览器报告精细指针时也可直输；原生系统输入法和候选窗口的体验需在实际设备确认。

切换焦点后若上一笔输入仍在处理中，再输入会明确提示“本次内容未发送”；等上一笔结束后手动重试，不会自动补发。粘贴前会复核实际 X11 输入窗口，窗口变化时不把文字粘贴到新目标。

打开文字输入助手，先核对目标终端，再点击“粘贴文字”。**粘贴不执行命令，Enter 单独提交**；图形终端粘贴使用 Ctrl+Shift+V。中文输入法组合期间不会自动发送。

“输入”打开同一个面板，在“发送到远程”和“取回文字”之间切换。取回需手动点击读取，先预览再复制到自己的设备，不自动同步两端剪贴板；切换方向或关闭面板会清空预览，发送草稿保留。草稿按当前标签页、节点和终端身份保留，不同步到其他设备。

“更多按键”提供固定组合，中断和结束类动作需确认，见[快捷键](shortcuts.md)。断线或执行回复未知时先核对远端结果，恢复连接不会补发输入。

## 查找与复制终端内容

网页终端直接拖选文字后，可在浏览器右键菜单中选择“复制”；Codex 等启用鼠标的程序也支持，无需等待程序返回剪贴板内容。程序输出的剪贴板读写请求继续被拦截。

点击“查找复制”，工具条从终端顶边向上展开，不改变终端尺寸。工具条和关键词在切换程序翻页、上翻 / 下翻、回到实时后继续保留；程序翻页后的查找、复制和下载读取当前已加载画面，不复用上一页快照。

普通回看与冻结的查找快照只操作本地历史；程序翻页模式会向远端程序发送翻页按键。仅展开工具条时终端仍可输入；从实时画面发起查找、复制或下载时，按需生成当前快照并暂停编辑输入。回到实时后恢复输入，工具条可继续保留。完整按键和滚轮行为见[历史与程序翻页](shortcuts.md#网页终端的程序翻页与回到实时)。

## 查看与显示

桌面默认按宽度缩放，可选择适应窗口、原始比例或手动缩放；本机滚动画面和滚动远程程序分别选择。网页终端提供选字复制、字号、宽度适配和历史阅读；首次打开的手机窄屏默认字号 10，其他屏幕默认 15，已有设置保留，具体范围见[浏览器偏好](browser-preferences.md#工具面板)。

显示偏好保存在当前浏览器的网站源，同源节点共用；服务器桌面分辨率属于远端共享设置，需要明确操作。快速切换待命仅桌面部署可选，默认关闭，开启会增加资源用量。范围见[浏览器偏好](browser-preferences.md)。

## 文件与设备

“文件中转”访问节点工作区下的 `transfer` 共同目录，可选择或拖入单个文件上传。每行可复制服务器完整路径，或将带引号的路径加入当前输入草稿，供 AI 读取；不会自动粘贴或执行。桌面视图还可打开远程共享目录。上传、同名替换、权限和直连规则见[文件说明](files.md)；结果未知时先刷新列表，不自动重传。

“端口映射”固定使用助手1至助手8，每台电脑运行一个助手，输入对应长期 key 后由网页管理规则。新增规则默认节点访问助手侧，使用单一“连接类型”选择 SSH、Web / HTTP、HTTPS 等用途，并自动预填可修改的名称与未被已知规则占用的监听端口。此方向的“复制 AI 提示词”说明拓扑和连接示例，另一方向保留“复制连接信息”。各助手独立显示直连 / 中转和网卡 / 串口清单，不自动执行终端命令。见[TCP 映射](forward.md)和[串口接入](serial.md)。

## 控制权与访问权限

同一工作台由一个页面持有桌面 / 终端控制权，新页接管后旧页停止输入。开启屏幕锁后，刷新或重新接管需要再次解锁；锁屏不停止后台任务，也不自动撤销已授权的映射。

临时账号可使用共享文件中转、查看连接状态，以及管理员逐个开放的助手 key；不能进入桌面、终端、配置映射或读取设备清单。完整权限见[屏幕锁与临时访问](access.md)。

## 在多个节点之间访问

| 入口 | 操作与影响 |
| --- | --- |
| Cloudflare 网关 | 工具中的“切换入口节点”或 `https://desk.example.com/__nodes/`；选择全局默认节点，后续访问使用新节点 |
| 自建中心 | 打开 `https://desk.example.com/` 查看在线节点，进入各自 `/node/<slug>/`；可分别收藏和打开，不改全局默认路由 |
| 独立域名 | 打开对应节点自己的域名 |

各节点账号、任务和文件分别管理。切换入口不迁移文件、不终止原任务，也不会把旧页面的写请求发给新节点。单节点部署不需要额外节点选择页。

输入面板会显示草稿保存状态，并提供复制当前草稿、导出本节点草稿。保存失败时，站内离开操作会先提示保护文字；浏览器自身刷新／关闭的提示受平台限制，见[草稿存储边界](browser-preferences.md#刷新多个页面与存储失败)。

“连接状态”按用途显示实际网络路径以及宿主 / 文件服务就绪情况，诊断与回退说明见[网络指南](lan.md)。
