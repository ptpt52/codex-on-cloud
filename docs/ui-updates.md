# 前端资源热更新

面板已经升级到支持热更新的版本后，文案、样式及与当前后台兼容的前端脚本可由部署用户执行：

```sh
npm run reload-ui
```

命令只访问 `data/panel/ui-reload.sock`，不重启任何服务、不改变登录或映射授权。此目录 0700、接口 0600，只接受固定维护动作；公网面板没有更新接口。旧版面板没有此接口，首次安装该能力需要正常重启一次面板，当次映射仍需重新配对。命令找不到接口时直接失败，不会给旧进程发送信号。

完整固定资源集经过文件类型、大小、JS 语法、模块路径及重复读取一致性检查后，原子发布一个版本。加载失败、文件缺失、资源仍在写入等情况保留上一版；新模块路径或后台 API 变化需要配套升级后台。此命令不构成后台代码热更新。

HTML 用带 CSP 哈希的 import map 锁定模块版本；CSS、普通 script 和后续打开的桌面/终端 frame 也携带原页面版本。已有页面与输入不会自动刷新，新开或手动刷新的页面取得新版本。页面每分钟前台检查一次版本，只显示更新提示。库资源使用当前安装的精确固定依赖，不在热更新中升级。

每文件最多 4 MiB，每版本原始资源最多 16 MiB，最多保留四个版本（含当前版），最多一个更新任务；固定集还会有转换和暂存内存。连续发布超过四版后，已淘汰页面再请求旧资源返回 410，需要保存草稿后刷新；正在运行的已加载画面不会因此被主动关闭。离线缓存只包含公开页面壳、最多四个资源缓存，认证、终端、桌面、文件与 API 不缓存。面板重启后内存旧版本清空。

超时可能是结果未知，命令不会自动重试。检查本机面板和 `/ui-version` 返回的资源版本后再操作。尚在使用的前端应保留后台协议兼容性；更新前运行项目测试。
