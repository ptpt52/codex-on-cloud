# 浏览器偏好与共享服务器设置

网页里的显示偏好属于当前浏览器配置文件，不随管理员账号或任务同步。它按网站源（协议、主机、端口）保存：同一域名下的 Cloudflare 网关节点、自建中心节点共用显示偏好；直连 IP 提示另按节点区分。不同源、不同浏览器配置文件及其他设备各自独立。

终端草稿另按当前标签页、节点 ID 和终端身份区分，不与上述显示设置混用。

## 设置保存在什么地方

| 范围 | 内容 | 生效方式 |
| --- | --- | --- |
| 当前浏览器的网站源 | 侧栏 / 顶部布局；网页终端字号、宽度适配、历史行数、程序鼠标；桌面缩放、触控、滚动目标、本机输入法；工具与输入面板折叠、操作模式 | 影响本机查看方式，刷新后恢复 |
| 当前浏览器的网站源 | 保持亮屏、快速切换待命、桌面跟随窗口选择 | 保存偏好；是否实际生效仍取决于页面可见性、权限和浏览器能力 |
| 当前浏览器与节点身份 | 节点主机 IP / 浏览器端 IP 直连提示 | 保存后用于新协商，可显式重新探测；本机地址可影响本轮接口选择 |
| 当前标签页与节点 | 所选终端、分终端输入草稿 | 校验 pane token，不能把旧终端草稿发给同槽位的新终端 |
| 当前页面运行状态 | 全屏、实际亮屏锁、剪贴板预览、网络诊断、在途输入 | 失权、隐藏或退出时按规则释放，不重发操作 |
| 共享服务器 | 桌面分辨率、窗口最大化 / 恢复、tmux 任务、账号和屏幕锁 | 通过对应服务器操作明确修改，影响远端共享状态 |

开启“桌面跟随窗口”可能调整共享远端分辨率，只有当前有控制权的页面可在空闲时执行；它不同于只在本机缩放像素画面。

## 工具面板

面板按常用操作、画面 / 终端显示、输入与触控、当前浏览器、服务器与访问分组；网页终端隐藏桌面专用项。标题、保存状态和关闭按钮保持可见，设置区域独立滚动，手机和平板也可随时关闭。界面布局、亮屏与快速切换待命集中在“当前浏览器”；服务器桌面设置、访问与屏幕锁放在“服务器与访问”，操作影响当前节点。

“服务器桌面设置”按桌面分辨率和服务器终端窗口分组：先保存固定分辨率，再显式应用；需要重启时另行确认。“访问与屏幕锁”按屏幕锁和临时账号分组，宽屏并排、窄屏纵向显示，各自保存。两个设置窗口均保留固定标题和结果反馈，内容独立滚动。

宽度达到 1200px 时默认使用左侧栏：上方是视图切换和纵向终端列表，下面依次为翻页 / 查找复制、常用操作、连接状态与账号。文件中转、端口映射、工具、输入、全屏和退出均在同一侧，工作区没有顶部工具行。终端列表独立滚动，上下方向键和 Home / End 会显示获得焦点的标签；窗口很矮时整条侧栏可以滚动，保留所有入口。

网页终端标签直接显示在侧栏中，固定占用剩余空间。翻页工具在加载或切换终端时暂时不可用，仍保留原位置；标签区不随之伸缩，标签过多时内部滚动。

标签区的可用高度不足以完整显示三个标签时，自动改用终端下拉选择，旁边保留当前终端操作入口；菜单列出全部终端及新建入口。高度恢复后重新显示列表，保留当前终端、连接和草稿。

桌面视图在侧栏与远程画面之间留出窄间隔，画面带细边框和圆角，便于区分工作台操作与远程桌面。

桌面视图在侧栏或顶部工具栏中列出已有终端任务，点击会激活对应窗口并同步输入助手目标。顶部布局会平铺能放下的标签，其余放入“更多终端”；手机和窄屏使用下拉选择。标签表示助手目标，不跟踪桌面上手动切换的窗口焦点；每个终端的操作菜单提供重命名和结束，创建也可通过“工具 → 终端管理”，结束前需要确认。

在“工具 → 界面布局”选择顶部工具栏，或点击侧栏底部“顶部布局”，即可恢复原布局；选择仅保存到当前浏览器。小于 1200px 时自动使用顶部布局，重新放大后恢复已选布局。切换只移动控件，保留当前终端连接、任务和未发送草稿；网页终端会根据新的可用空间调整排版。

打开工具、输入或查找复制使用浮层，不占用终端高度。侧栏的程序翻页、上下翻、回到实时和查找复制保留深色背景平铺显示，与右侧终端留出窄间隔，不加外框、圆角或阴影；状态提示固定预留两行，切换时按钮保持原位。查找复制从终端内部顶边展开，与终端等宽，不另加悬浮卡片阴影。顶部布局仍在终端上方展开。查找框输入与终端输入互不代发，进入历史快照后才暂停终端编辑。

桌面视图显示缩放、触控、滚动、本机输入法、图形终端和服务器桌面设置；网页终端显示目标、宽度、字号、历史和程序鼠标设置。切换视图需确认，隐藏另一视图的控件不会清空原偏好。纯终端部署只提供网页终端工具。本机输入法默认开启，网页终端的程序鼠标默认关闭；两者独立，不改动远程程序的配置。

两种视图共用终端管理、重新连接、全屏、亮屏及有权限的访问设置。节点切换仅在对应多节点入口可用时显示。

“工具 → 终端管理”在顶部显示已用名额、刷新和操作结果；列表独立滚动，关闭按钮始终可见。新建入口位于列表上方，名额用满后提示先结束不用的终端。每个终端显示名称和当前程序，网页终端标记“当前终端”，桌面视图标记已选的“输入目标”；点击“重命名”才展开编辑，保存后同步标签和列表，取消或按 Esc 放弃编辑。结束终端仍需再次确认，会停止该会话及其前台任务。旧草稿清理位于“草稿与使用说明”，只影响当前浏览器中的旧草稿。

网页终端字号在手机窄屏（初次打开时宽度 ≤700px）默认 10，其他屏幕默认 15，范围 10–28；已有字号偏好保持不变，旋转或调整窗口不会自动改字号。历史默认 10000 行，可选 2000 / 5000 / 10000 / 20000。它们控制浏览器查看器；视口适配仍可能改变共享 tmux 窗口的排版，不会重启原任务。遇到 tmux 2.6 时，网页按偶数列适配，最多少用一列，避免缩窄后旧中文行超出边界；其他版本仍逐列适配。

行高按当前字体自动为中文留足空间，避免小字号时笔画被截断；终端关闭浏览器自动添加的中英间距，保持文字与字符网格一致。上翻后的历史快照沿用实时终端的列宽、行距和颜色样式，调整字号后同步更新；内容与原有换行保持不变，过宽的历史行可横向查看。极端复杂的历史记录会提示排版或样式简化，文字仍可完整复制和下载。

网页终端按当前节点 tmux 的字符宽度显示 Emoji 和组合字符，避免后续文字或光标错列；旧系统尚未识别的字符也沿用该节点的处理方式。重连会复用经过节点身份校验的字宽表，不会升级 tmux、重启终端任务或修改用户配置。

图形桌面是同一份远端像素画面，原生终端字体会影响所有观看端，阅读大小优先使用本机缩放。新建 / 重新打开图形终端默认最大化，已有窗口布局不会因普通浏览器重连而重置。旧 `fontSize` 仅保留为原生维护兼容默认，不是本机网页字号。

## 快速切换待命

桌面部署可在“工具 → 快速切换待命”开启，默认关闭。最多同时保留一个桌面查看器和一个所选网页终端查看器，后台终端标签不会各占一个连接。切换仍需确认，待命未就绪时使用正常连接流程。

网页终端选择目标后切回桌面，会打开或聚焦同一个终端窗口，确认完成前暂停输入。桌面标签优先通过已建立的查看会话切换窗口，后台未声明此能力时使用原 HTTP 接口；已经发送的操作不会因断线改走另一条路径重试。桌面改变所选终端时保留待命网页终端，返回网页终端后在原会话上附加新目标，不为每个标签重新加载页面或建立 WebRTC 连接。

返回网页终端时，后台会先等待旧查看器的显示恢复和尺寸回执，最多 1.5 秒，再检查并附加目标终端；这段短暂恢复不会直接撤销已经选择的新目标。真正忙碌、权限变化或目标失效时仍拒绝切换，不重发输入。

待命桌面恰在恢复连接时，本次切换最多等待 1.5 秒再首次发送聚焦操作；超时后解除等待，不在稍后重连时自动执行。窗口未确认切换时取消标签高亮并暂停输入助手，重新点击目标标签后恢复。

待命持续接收输出和心跳，会增加浏览器内存、服务器连接和网络用量；不接受输入，不重启终端任务。锁屏、被接管、退出、隐藏或离开页面时释放待命，返回前台且仍有权限时重新准备。纯终端部署不提供此选项。

## 刷新、多个页面与存储失败

新页面读取最后保存的选择；已经打开的其他页面不会因此自动切换模式、抢占控制权或调整服务器。每次保存只合并用户刚修改的字段，避免旧页面覆盖其他选项。

亮屏默认关闭，只由前台且有控制权的页面申请实际亮屏锁；失权或退出会释放锁，已保存的选择保留。隐私模式与常规配置文件隔离，保留期限由浏览器决定。

浏览器禁止存储或写入失败时，设置仅在当前页面有效并显示提示，不会改为写入服务器。输入面板显示草稿保存状态，可复制当前草稿，或将本节点草稿导出为 JSON 文件；顶部“草稿”入口在软键盘弹出时仍可使用。导出包含因容量不足而未能存入的当前编辑内容；不会包含账号、Cookie、CSRF 或其他节点的草稿。

存在未安全保存的草稿时，站内切换节点、退出或点击刷新入口会先显示保护窗口，默认留在当前页面；复制或导出不会自动离开，仍需明确选择“仍然离开”。正常保存的草稿不增加确认步骤。浏览器自身刷新、关闭使用原生离开提示；移动端强制关闭或系统回收页面时可能不触发，不能把提示当作持久备份。草稿丢失不代表远端任务结束。

## 资源边界（开发参考）

- 显示偏好：`codex-cloud.display.v1`，一个 localStorage 条目，最多 512 字符，仅固定字段白名单，不保存账号、Cookie、CSRF 或终端正文。
- IP 提示：`codex-cloud.rtc-hints.v2`，按节点身份或节点路径保存，总计最多 64 KiB、保留 90 天，按最后保存时间淘汰；每节点一对可选地址。旧 v1 提示须手动导入到当前节点；发送给节点参与 ICE，见[直连提示](lan.md#浏览器手动地址提示)。
- 草稿：sessionStorage 中按节点 ID 分开；每份最多 32768 字符，每节点最多九份，同一标签页最多持久保存 16 个节点、合计 2 MiB。此上限不限制服务器节点目录。
- 手动草稿导出：本节点最多九份保留草稿加一份未保存的当前编辑内容，单个 JSON 最多 2 MiB；复用有界下载链接，不在服务器新增文件。

存储键和验证规则以[显示偏好实现](../panel/public/browser-preferences.js)、[地址提示](../panel/public/rtc-hints.js)和[草稿实现](../panel/public/terminal-state.js)为准。部署项与生效服务见[配置参考](deployment-config.md)。
