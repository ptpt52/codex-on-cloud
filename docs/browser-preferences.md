# 浏览器偏好与共享服务器设置

同一浏览器配置文件、同一节点站点下，主终端和辅助终端共用一份显示偏好；不同电脑、手机、浏览器配置文件和节点 origin 各自独立。隐私会话与常规配置文件隔离，其保留期限遵循浏览器规则。偏好属于访问设备，不随管理员账号或终端任务同步。

宽度不超过 420 像素时，工具栏只显示切换到另一模式的按钮，点击后仍需确认；当前模式可从工作区和操作模式分组名称识别。终端选择入口至少 72×44 像素，快捷关闭保持 44×44；默认主终端在窄屏显示“主终端”，读屏名称和自定义终端名称保持完整。该布局自动随窗口调整，不新增偏好或额外工具栏行。

| 范围 | 设置或状态 | 保存与生效 |
| --- | --- | --- |
| 当前浏览器 | 网页终端字号、宽度适配、网页历史行数 | 调整当前查看器；所有终端标签共用，切换及刷新后恢复 |
| 当前浏览器 | 桌面缩放、拖动画面、触控方式、滚动目标、操作模式、工具与输入面板折叠 | 保留本机阅读与操作习惯，不写服务器配置 |
| 当前浏览器 | 保持亮屏、桌面跟随窗口策略 | 只保存本机选择；实际亮屏锁只由前台且有控制权的页面申请；跟随窗口仅在当前查看者有权限且空闲时调整共享显示 |
| 当前浏览器 | 快速切换待命 | 默认关闭；开启后仅当前页面同时准备桌面和所选网页终端，确认切换时复用查看器与连接 |
| 当前浏览器 | 可选的服务器 IP、浏览器端 IP 直连地址提示 | 独立于显示偏好保存；随后续已认证直连协商发给服务端，不修改服务器部署配置或既有连接 |
| 当前页面 | 全屏状态、实际亮屏锁、网络诊断、剪贴板预览、正在处理的输入 | 不作为持久化偏好；失权、隐藏或卸载按原规则释放，不重发输入 |
| 当前网页标签 | 所选终端身份、分终端输入草稿 | 使用原有受限 sessionStorage，校验 pane token，不与其他浏览器同步 |
| 共享服务器 | 已保存和实际应用的桌面分辨率、窗口最大化/恢复、tmux 任务、服务端历史容量、账号/屏幕锁 | 必须通过对应服务器操作修改；界面明确标为服务器设置，不混入浏览器偏好 |

工具面板按当前操作模式显示对应设置，隐藏另一模式的控件，不清空其已保存的偏好。模式切换仍需明确确认；纯终端部署始终显示网页终端工具。

| 工具显示范围 | 内容 |
| --- | --- |
| 桌面模式 | 打开图形终端、适应宽度/窗口/原始比例与缩放、触控方式、滚动目标、拖动画面、服务器桌面设置 |
| 网页终端模式 | 查看目标、宽度适配、字号、网页历史行数 |
| 两种模式共用 | 终端管理、重新连接、全屏、保持亮屏、快速切换待命、节点切换（已接入网关时）、访问与屏幕锁；立即锁定仍按原权限和配置显示 |

桌面设置入口中的共享分辨率和窗口操作只在桌面模式提供；网页终端的字号、宽度和历史继续属于当前浏览器。网页终端的目标、宽度、字号和历史分行显示，窄屏也保留可读的宽度选项。工具可见性由模式明确设置 `hidden`，不依赖可能被布局样式覆盖的隐藏规则；显示区域的无障碍标签也随模式更新。

“工具 → 快速切换待命”默认关闭，并保存到上述浏览器偏好条目。开启后最多保留两个查看器（桌面一个、网页终端一个），后台终端标签不会各占一个连接。切换仍需确认；待命未就绪或目标身份不匹配时按原方式连接。桌面尚未选择输入目标时只预备主终端，不改变所选目标或迁移草稿；明确选择其他目标后重建对应待命终端。直连和中转均可复用，实际路径仍按原探测和回退策略选择。

待命查看器保持接收输出和心跳，因此增加浏览器内存、服务端连接和网络用量。它不接受焦点、触摸、普通按键或输入助手操作；网页终端待命时不主动发送远端尺寸调整，必要的终端查询回复与输出确认继续工作。关闭开关、锁屏、被接管、退出、页面转入后台或离开时释放待命查看器；回到前台且仍有权限时重新预备。开关变化仅重建观看连接，不重启桌面、tmux 或 Codex，不重发输入和审批。纯终端部署隐藏该选项；旧服务端没有相应能力时不可开启。

网页终端进入待命时，原生 PTY 归还之前借用的桌面 Xterm，停止周期性接管，并跟随其他 tmux 客户端的实际尺寸，避免待命连接限制桌面大小。初次预备也从当前共享窗口尺寸附加，不先缩成 80×24。切回网页终端后再恢复本浏览器的宽度策略；上述操作不结束或重启终端任务。

网页终端字号默认为 15，范围 10–28；历史默认为 10000 行，可选 2000 / 5000 / 10000 / 20000。字号和历史行数只影响浏览器的文字查看器；当前 PTY 的行列作为运行状态随视口适配，同一 tmux 任务的排版可能变化，不改变其进程、配置或服务器的默认字号。亮屏默认关闭，退出或被接管释放实际锁，保存的本机选择保留。

服务器新建/重新打开图形终端时默认最大化；已有窗口的手动恢复和布局在再次打开或浏览器重连时保留。这项窗口默认与浏览器字号、画面缩放分别管理。

桌面是同一个远端像素画面，原生 xterm 字体修改会影响所有观看端。网页不再提供“新终端字号 / 更新字号”的全局入口，桌面阅读大小使用当前浏览器的缩放按钮；网页终端使用自己的字号控制。`data/desktop-settings.json` 中旧的 `fontSize` 保留为原生图形终端启动/维护兼容默认，新网页不将它读作本机字号，也不随分辨率保存上传字号。旧的受认证维护 API 与私有 manager 操作保持兼容；它们不是浏览器偏好接口。

显示偏好使用 `codex-cloud.display.v1` 一个 localStorage 条目，上限 512 字符，逐项验证并只写固定白名单。旧布局仍迁移到固定尺寸、适应宽度，保留折叠/拖动布尔选项；当前布局的一个无效字段不会清空其他有效设置。该条目不保存账号、Cookie、CSRF、服务器宽高、任务或终端正文。禁止存储或写入失败时仅在当前页面生效，并显示提示，不回退为服务器保存。

直连地址提示另用 `codex-cloud.rtc-hints.v1`，一对可选 IP、最多 256 字符。显示偏好不随协商上传，地址提示按用途发送给服务端参与 ICE 探测。填写、清除与生效规则见[直连地址提示](lan.md#浏览器手动地址提示)。

同一浏览器的新页面和刷新读取最后保存的选择。已打开页面不因其他标签写入而自动切换模式、抢占控制权或调整服务器；每次保存仅把本次更改合入最新存储，避免旧页面覆盖其他页面修改的无关选项。后台/直连切换只恢复当前页面已有偏好，不执行窗口重建、提交提示词、Enter 或审批。

验收重点：两份独立浏览器配置使用不同字号和亮屏选择、同浏览器的新页面及辅助终端继承本机偏好、存储禁用仍可操作，以及更改阅读偏好不调用服务器设置或全局字号动作。服务器分辨率单独保存时保留旧的原生字体默认值。
