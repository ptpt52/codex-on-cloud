# 浏览器偏好与共享服务器设置

网页里的显示偏好属于当前浏览器配置文件，不随管理员账号或任务同步。它按网站源（协议、主机、端口）保存：同一域名下的 Cloudflare 网关节点、自建中心节点共用显示偏好；直连 IP 提示另按节点区分。不同源、不同浏览器配置文件及其他设备各自独立。

终端草稿另按当前标签页、节点 ID 和终端身份区分，不与上述显示设置混用。

## 设置保存在什么地方

| 范围 | 内容 | 生效方式 |
| --- | --- | --- |
| 当前浏览器的网站源 | 侧栏 / 顶部布局；网页终端字号、宽度适配、历史行数、滚轮策略、程序鼠标；桌面缩放、触控、滚动目标、本机输入法；工具与输入面板折叠、操作模式 | 影响本机查看方式，刷新后恢复 |
| 当前浏览器的网站源 | 保持亮屏、快速切换待命、桌面跟随窗口选择 | 保存偏好；是否实际生效仍取决于页面可见性、权限和浏览器能力 |
| 当前浏览器的网站源 | 网络调试日志开关（默认关闭） | 当前页面立即生效，同网站其他打开页面同步；不重连、不调整画面 |
| 当前浏览器与节点身份 | 节点主机 IP / 浏览器端 IP 直连提示 | 保存后用于新协商，可显式重新探测；本机地址可影响本轮接口选择 |
| 当前标签页与节点 | 所选终端、分终端输入草稿 | 校验 pane token，不能把旧终端草稿发给同槽位的新终端 |
| 当前标签页与节点 | 已开启的网络调试日志 | 有界保留，刷新后可读取；关闭开关、退出或清空时删除当前节点记录 |
| 当前页面运行状态 | 全屏、实际亮屏锁、剪贴板预览、网络诊断、在途输入 | 失权、隐藏或退出时按规则释放，不重发操作 |
| 共享服务器 | 桌面分辨率、窗口最大化 / 恢复、tmux 任务、账号和屏幕锁 | 通过对应服务器操作明确修改，影响远端共享状态 |

开启“桌面跟随窗口”可能调整共享远端分辨率，只有当前有控制权的页面可在空闲时执行；它不同于只在本机缩放像素画面。

开启“快速切换待命”最多保留一个活动查看器和一个待命查看器。首次进入统一会话时，在确认控制权和任务宿主就绪后并行加载待命查看器；待活动连接就绪，再开始待命建连，避免模块串行加载，也避免待命协商抢占活动连接。手机熄屏或切到其他应用时保留这两个页面上下文，暂停后台心跳和重试；返回前台后各自恢复连接，避免重新下载和初始化待命页面。待命桌面停止持续请求画面、禁止输入，切回后仍需确认新画面和窗口焦点。离开页面、退出、失去控制权或关闭此选项会释放待命查看器；浏览器回收页面后也需要重新连接。活动终端显示直连，只说明该终端的路径，不能证明待命桌面已就绪。

## 工具面板

面板按常用操作、画面 / 终端显示、输入与触控、当前浏览器、服务器与访问分组；网页终端隐藏桌面专用项。标题、保存状态和关闭按钮保持可见，设置区域独立滚动，手机和平板也可随时关闭。界面布局、亮屏、快速切换待命和网络调试日志集中在“当前浏览器”；服务器桌面设置、访问与屏幕锁放在“服务器与访问”，操作影响当前节点。

“服务器桌面设置”按桌面分辨率和服务器终端窗口分组：先保存固定分辨率，再显式应用；需要重启时另行确认。“访问与屏幕锁”按屏幕锁和临时账号分组，宽屏并排、窄屏纵向显示，各自保存。两个设置窗口均保留固定标题和结果反馈，内容独立滚动。

宽度达到 1200px 时默认使用左侧栏：上方是视图切换和纵向终端列表，下面依次为翻页 / 查找复制、常用操作、连接状态与账号。文件中转、端口映射、工具、输入、全屏和退出均在同一侧，工作区没有顶部工具行。终端列表独立滚动，上下方向键和 Home / End 会显示获得焦点的标签；窗口很矮时整条侧栏可以滚动，保留所有入口。

网页终端标签直接显示在侧栏中，固定占用剩余空间。翻页工具在加载或切换终端时暂时不可用，仍保留原位置；标签区不随之伸缩，标签过多时内部滚动。

标签区的可用高度不足以完整显示三个标签时，自动改用终端下拉选择，旁边保留当前终端操作入口；菜单列出全部终端及新建入口。高度恢复后重新显示列表，保留当前终端、连接和草稿。

桌面视图在侧栏与远程画面之间留出窄间隔，画面带细边框和圆角，便于区分工作台操作与远程桌面。

桌面视图在侧栏或顶部工具栏中列出已有终端任务，点击会激活对应窗口并同步输入助手目标。顶部布局会平铺能放下的标签，其余放入“更多终端”；手机和窄屏使用下拉选择。标签表示助手目标，不跟踪桌面上手动切换的窗口焦点；每个终端的操作菜单提供重命名和结束，创建也可通过“工具 → 终端管理”，结束前需要确认。

在“工具 → 界面布局”选择顶部工具栏，或点击侧栏底部“顶部布局”，即可恢复原布局；选择仅保存到当前浏览器。小于 1200px 时自动使用顶部布局，重新放大后恢复已选布局。切换只移动控件，保留当前终端连接、任务和未发送草稿；网页终端会根据新的可用空间调整排版。

打开工具、输入或查找复制使用浮层，不占用终端高度。侧栏的程序翻页、上下翻、回到实时和查找复制保留深色背景平铺显示，与右侧终端留出窄间隔，不加外框、圆角或阴影；状态提示固定预留两行，切换时按钮保持原位。查找复制从终端内部顶边展开，与终端等宽，不另加悬浮卡片阴影。顶部布局仍在终端上方展开。查找框输入与终端输入互不代发，进入历史快照后才暂停终端编辑。

桌面视图显示缩放、触控、滚动、本机输入法、图形终端和服务器桌面设置；网页终端显示目标、宽度、字号、历史、程序翻页时的滚轮和程序鼠标。切换视图需确认，偏好会保留。纯终端部署只提供网页终端工具。桌面本机输入法默认开启，网页终端的程序鼠标默认关闭。滚轮策略与点击、拖选设置独立，见[程序翻页](shortcuts.md#网页终端的程序翻页与回到实时)。

手机、平板在桌面画面右下角提供“键盘”：先点远程终端或应用的输入位置，再点“键盘”用系统输入法直输中文。快捷栏提供 Esc、Tab、退格和 Enter，方向键在窄屏的“更多”中，宽屏直接显示上下键；使用快捷键保持键盘焦点。选字确认和软键盘回车不执行命令，提交请点快捷栏 Enter；实体键盘 Enter 保留原操作。Ctrl+C 在“更多”中，仍需确认，发送到桌面当前焦点，不采用输入助手记住的旧终端目标。

“长文本”打开原输入助手，保留草稿、编辑和手动粘贴流程，适合长提示词或多行文本。iPhone / iPad 在桌面直输和网页终端中保留当前输入段的原生编辑上下文，实时发送增量，也支持听写改词和补标点；不会把每次更新的整段文字重复追加。当前输入段最多 32 KiB，一次改写最多退格 512 个字符组合；超限时暂停并提示核对。桌面改写还会检查是否仍为原输入窗口。

该上下文只保存在当前页面内存中，不是远端编辑器的完整副本。收起键盘、失焦、导航按键、锁屏或断线会结束当前段，未完成的输入不会自动重发；断线后先核对远端再继续输入。Android 沿用原输入路径。快捷栏跟随浏览器可见区域，键盘打开期间暂停服务器桌面的自动尺寸调整；不改变原分辨率或重启任务。连接实体键盘的平板仍可沿用电脑操作。关闭“本机输入法直输中文”后触屏直输入口隐藏，原输入助手可继续使用。

触屏输入助手点击“粘贴文字”或常用按键时，焦点保留在本地草稿框，便于继续输入；粘贴不清空草稿、不自动回车。需要确认的操作仍打开确认窗口。

两种视图共用终端管理、重新连接、全屏、亮屏及有权限的访问设置。节点切换仅在对应多节点入口可用时显示。

“工具 → 终端管理”在顶部显示已用名额、刷新和操作结果；列表独立滚动，关闭按钮始终可见。新建入口位于列表上方，名额用满后提示先结束不用的终端。每个终端显示名称和当前程序，网页终端标记“当前终端”，桌面视图标记已选的“输入目标”；点击“重命名”才展开编辑，保存后同步标签和列表，取消或按 Esc 放弃编辑。结束终端仍需再次确认，会停止该会话及其前台任务。旧草稿清理位于“草稿与使用说明”，只影响当前浏览器中的旧草稿。

网页终端关闭当前标签后，停留在当前位置，显示“已关闭”和可直接点击的“新开终端”按钮，不自动切换其他终端。点击画面中的按钮或标签栏的“新开终端”才创建 shell，也可手动选择已有终端，继续复用当前查看连接。终端自行退出或附加失败时保留最后画面。未附加终端的查看连接最多保留 60 秒，超时后按需重连；任务不会自动重启。操作结果未知时先刷新列表核对，不重复关闭，也不自动选择另一终端。

切换终端时，已就绪的直连和中转备用连接同步目标后继续使用，不按标签反复建立连接。备用连接同步超时会单独重建，当前画面继续使用活动路径；仍只有一条路径可发送业务输入。

网页终端字号在手机窄屏（初次打开时宽度 ≤700px）默认 10，其他屏幕默认 15，范围 10–28；已有字号偏好保持不变，旋转或调整窗口不会自动改字号。历史默认 10000 行，可选 2000 / 5000 / 10000 / 20000。它们控制浏览器查看器；视口适配仍可能改变共享 tmux 窗口的排版，不会重启原任务。遇到 tmux 2.6 时，网页按偶数列适配，最多少用一列，避免缩窄后旧中文行超出边界；其他版本仍逐列适配。

行高按当前字体自动为中文留足空间，避免小字号时笔画被截断；终端关闭浏览器自动添加的中英间距，保持文字与字符网格一致。上翻后的历史快照沿用实时终端的列宽、行距和颜色样式，调整字号后同步更新；内容与原有换行保持不变，过宽的历史行可横向查看。极端复杂的历史记录会提示排版或样式简化，文字仍可完整复制和下载。

网页终端按当前节点 tmux 的字符宽度显示 Emoji 和组合字符，避免后续文字或光标错列；旧系统尚未识别的字符也沿用该节点的处理方式。重连会复用经过节点身份校验的字宽表，不会升级 tmux、重启终端任务或修改用户配置。

历史画面保留终端折行，搜索、复制和下载则连接自动折行的部分，长命令不会被插入换行；原文主动换行仍然保留。远端补取的历史按快照记录的终端列数显示，跨行搜索与复制方式相同。

较大的历史快照会分批排版，等待时仍可回到实时；搜索只更新高亮，复用已有排版。排版完成后整份快照可以连续选择，复制全部和下载始终使用完整快照。

图形桌面是同一份远端像素画面，原生终端字体会影响所有观看端，阅读大小优先使用本机缩放。新建 / 重新打开图形终端默认最大化，已有窗口布局不会因普通浏览器重连而重置。旧 `fontSize` 仅保留为原生维护兼容默认，不是本机网页字号。

## 快速切换待命

桌面部署可在“工具 → 快速切换待命”开启，默认关闭。最多同时保留一个桌面查看器和一个所选网页终端查看器，后台终端标签不会各占一个连接。切换仍需确认，待命未就绪时使用正常连接流程。

开启或关闭此选项只准备或释放另一个视图，当前查看器、连接和输入草稿继续保留。服务端在当前连接建立时声明支持双视图；关闭待命时仍只运行正在使用的查看器。

网页终端选择目标后切回桌面，会打开或聚焦同一个终端窗口，确认完成前暂停输入。桌面标签优先通过已建立的查看会话切换窗口，后台未声明此能力时使用原 HTTP 接口；已经发送的操作不会因断线改走另一条路径重试。桌面改变所选终端时保留待命网页终端，返回网页终端后在原会话上附加新目标，不为每个标签重新加载页面或建立 WebRTC 连接。

网页按视口调整终端尺寸，以及从桌面返回网页、从网页返回桌面时，后台都会在尺寸稳定后通知终端程序，连续往返也会重新通知。通过 `systemd-run --pipe` 或 `setsid` 启动、继承终端输入输出的本机程序也会收到通知，不仅通知外层启动脚本。开启待命和关闭网页连接的返回路径都适用；任务、前台程序或对应查看连接已变化时取消通知，不发送点击、翻页、按键或回车。

返回网页终端时，后台会先等待旧查看器的显示恢复和尺寸回执，最多 1.5 秒，再检查并附加目标终端；这段短暂恢复不会直接撤销已经选择的新目标。真正忙碌、权限变化或目标失效时仍拒绝切换，不重发输入。

待命桌面恰在恢复连接时，本次切换最多等待 1.5 秒再首次发送聚焦操作；超时后解除等待，不在稍后重连时自动执行。窗口未确认切换时取消标签高亮并暂停输入助手，重新点击目标标签后恢复。

待命桌面在首帧完成后暂停请求 VNC 画面，保持连接及心跳；网页终端待命时继续接收输出。返回桌面时，先确认目标终端窗口，再请求完整画面并等待绘制完成后开放输入。刷新超时只重连观看通道，任务继续运行，输入不会重发。待命仍占用浏览器内存和服务器连接，不接受输入，不重启终端任务。锁屏、被接管、退出、隐藏或离开页面时释放待命，返回前台且仍有权限时重新准备。纯终端部署不提供此选项。

## 网络调试日志

排查直连、熄屏恢复或模式切换时，在“工具 → 当前浏览器 → 网络调试日志”开启；“连接状态 → 网络日志与当前进度”提供同一开关。默认关闭时不采集过程事件；基本连接状态和操作结果提示继续显示。开关不创建连接、不调整远程画面，不改变已有恢复和输入保护。

当前进度分别显示前台和待命视图的模块加载、连接路径、首帧和 WebRTC 探测状态。网页终端直连不代表待命桌面已经加载完成；“首帧已接收”也不代替切换时的新画面与输入就绪检查。日志关闭时仍显示这些即时状态和自动探测停止原因，但不保留过程历史。

日志达到现有条数或大小上限时，优先淘汰常规心跳、统计和过程采样，保留故障、视图生命周期、首帧和路径切换记录，同时保留最近 32 条上下文；重要记录本身过多时仍按上限淘汰，超过 24 小时全部过期。协商排队阶段单独记录，便于区分本页等待名额和服务端繁忙。

开启后重现问题，再点“一键复制网络日志”发给分析者；剪贴板权限不可用时会展开已选中的文字，可手动复制。“导出日志”下载同一份 JSON。“清空记录”只清空当前节点，仍继续记录；关闭开关则同时停止记录、取消待写入记录并清空当前节点的本地记录、复制预览及临时下载链接。已明确复制到系统剪贴板或下载的文件不由网页删除。

开关保存在同源 `codex-cloud.display.v1` 的 `networkDebug` 布尔字段；同网站其他已打开页面同步开关，其他显示选择继续保持。记录放在当前标签页的 `sessionStorage`，按节点 ID、无 ID 时按入口路径隔离：每节点最多 200 条和 64 KiB，同标签页最多 4 个节点、合计 256 KiB。只读取、导出最近 24 小时的记录，下次写入清理过期项。刷新和熄屏返回可继续读取，退出登录会清空当前节点。浏览器存储不可用时仅当前页面内存有效。

JSON 包含界面版本、平台、前后台状态、各视图当前路径，以及信令、ICE、心跳、候选比较、排空与重试过程。`path: direct` 表示 WebRTC 通道，`route` 进一步区分局域网、NAT、IPv6、VPN、公网 IPv4、TURN、WSS 和 HTTPS；不能仅凭 `direct` 断定没有经过 TURN，统计不可用时保留 `unknown`。`time` 为实际时间，`page` 区分刷新前后的同号视图；`capture` 注明开始时间、保留上限、当前页面内因上限丢弃及重复合并的数量。200 条滚动记录不是完整历史，只有开启后的事件可用于排查。

控制故障额外记录固定白名单中的 `action` 名称和耗时，区分浏览器 RPC 超时、节点本机 HTTP 超时或中断、远端关闭、协议错误、发送失败和心跳失败。迟到回复排空会单独记录恢复事件，不把原来的“结果未知”改成成功，也不重发操作。正常控制请求成功不逐次写入日志。

手动直连重测每次最多增加开始、准备切换、结束三条事件。结束事件记录固定阶段 `step`、重测结果 `result`、耗时以及可用的错误类别、HTTP 状态和确认结果，区分候选协商、心跳验证、等待空闲与切换接管失败。阶段表示客户端进行到的位置，不保证服务端已完成切换；进入切换阶段后缺少明确确认按结果未知记录。重测失败提示以下方实际连接状态为准，不把旧连接仍可用当作既定事实。

只记录固定白名单字段，不记录 IP、SDP、账号、Cookie、授权 key、终端文字、文件名或请求正文；任意动作名称和错误正文不进入记录，复制与导出使用同一脱敏结果。心跳成功日志按 15 秒采样，半秒内相同的前后台或断连事件合并；平时合并为每 250 毫秒一次存储写入，页面隐藏或离开时立即写入。界面显示保留、淘汰和合并数量。这些限制只作用于日志，不改变实际心跳、重连频率或输入确认。备份原生服务日志、抓包和整机网络审计不在此开关范围内。

## 刷新、多个页面与存储失败

通过浏览器后退或前进恢复缓存页面时，输入先暂停，并通过当前节点重新核对登录、屏幕锁和控制权。桌面查看器重新创建；网页终端保留本地缓冲和草稿，按原身份恢复连接。未确认的输入、窗口聚焦、创建和审批操作不会重发。

新页面读取最后保存的选择；已经打开的其他页面不会因此自动切换模式、抢占控制权或调整服务器。每次保存只合并用户刚修改的字段，避免旧页面覆盖其他选项。

亮屏默认关闭，只由前台且有控制权的页面申请实际亮屏锁；失权或退出会释放锁，已保存的选择保留。隐私模式与常规配置文件隔离，保留期限由浏览器决定。

浏览器禁止存储或写入失败时，设置仅在当前页面有效并显示提示，不会改为写入服务器。输入面板显示草稿保存状态，可复制当前草稿，或将本节点草稿导出为 JSON 文件；顶部“草稿”入口在软键盘弹出时仍可使用。导出包含因容量不足而未能存入的当前编辑内容；不会包含账号、Cookie、CSRF 或其他节点的草稿。

存在未安全保存的草稿时，站内切换节点、退出或点击刷新入口会先显示保护窗口，默认留在当前页面；复制或导出不会自动离开，仍需明确选择“仍然离开”。正常保存的草稿不增加确认步骤。浏览器自身刷新、关闭使用原生离开提示；移动端强制关闭或系统回收页面时可能不触发，不能把提示当作持久备份。草稿丢失不代表远端任务结束。

## 资源边界（开发参考）

- 显示偏好：`codex-cloud.display.v1`，一个 localStorage 条目，最多 512 字符，仅固定字段白名单，不保存账号、Cookie、CSRF 或终端正文。
- IP 提示：`codex-cloud.rtc-hints.v2`，按节点身份或节点路径保存，总计最多 64 KiB、保留 90 天，按最后保存时间淘汰；每节点一对可选地址。旧 v1 提示须手动导入到当前节点；发送给节点参与 ICE，见[直连提示](lan.md#浏览器手动地址提示)。
- 草稿：sessionStorage 中按节点 ID 分开；每份最多 32768 字符，每节点最多九份，同一标签页最多持久保存 16 个节点、合计 2 MiB。此上限不限制服务器节点目录。
- 手动草稿导出：本节点最多九份保留草稿加一份未保存的当前编辑内容，单个 JSON 最多 2 MiB；复用有界下载链接，不在服务器新增文件。

存储键和验证规则以[显示偏好实现](../panel/public/browser-preferences.js)、[地址提示](../panel/public/rtc-hints.js)和[草稿实现](../panel/public/terminal-state.js)为准。部署项与生效服务见[配置参考](deployment-config.md)。
