      下载助手与安装说明

      请选择运行助手的电脑版本。

      助手下载：HTTPS；WebRTC 就绪后优先使用

      Mac 首次运行：若提示“Apple 无法验证”，进入“系统设置 → 隐私与安全性”，对 codex-cloud-forward 点击“仍要打开”，确认后重新运行 Start.command。完整步骤见下方说明。

      Mac 首次运行 / Apple 无法验证时怎么办

      需要 macOS 12 或更新版本。解压 ZIP，双击 Start.command，在终端窗口粘贴对应助手的授权 key。本版尚未进行 Developer ID 签名及 Apple 公证，首次运行可能出现“Apple 无法验证 codex-cloud-forward”的提示。

      1. 确认下载来源并核对网页显示的 ZIP SHA256，然后尝试打开程序。出现验证提示时，点击“完成”或“取消”。
      2. 进入“系统设置 → 隐私与安全性”，向下滚动到“安全性”，找到刚被阻止的 codex-cloud-forward，点击“仍要打开”，并按系统提示确认。
      3. 重新双击 Start.command。如果提示阻止的是 Start.command，也需对该文件按上述步骤确认。

      没有看到“仍要打开”时，先在解压文件夹中双击 codex-cloud-forward，再返回设置查看。按Apple 官方说明确认此程序即可，无需关闭系统整体安全检查。也可在终端进入该文件夹运行 ./codex-cloud-forward。

      解锁并接管工作台后，可管理助手、key 和规则。下方仍可下载助手。

      助手1

      下载并打开助手 → 粘贴此 key → 保持窗口运行。同一 key 只接入一台电脑。

      仅控制网页查看权限。已复制的 key 不会随关闭可见或临时账号到期而失效；要撤销旧 key，请重新生成。

      此助手的 key 由管理员开放。刷新只重新读取当前 key；规则和设备信息由管理员管理。

      映射规则

      网卡和串口信息

      状态自动更新
      连接方式与使用限制

      新连接优先加密直连，不可用时使用 WSS 中转。监听仅绑定 127.0.0.1。固定 8 个助手，每助手最多 16 条规则，全节点最多 32 条活动映射。网页退出或锁屏不撤销助手授权；管理员重新生成 key 会断开对应助手，规则保留。临时账号的“刷新 key”仅读取当前 key。节点重启后按保存规则重建映射，已断开的 TCP 和串口字节不会重放。

      新增规则

      节点主机：运行网页终端 / AI 的主机。助手电脑：运行下载助手的电脑。

      助手电脑上的串口

      每个串口仅允许一个客户端，使用原始 TCP，无硬件流控。打开串口时 DTR/RTS 可能跳变并使设备复位。常驻助手自动上报串口列表，也可手动填写；只在业务客户端接入后打开设备。

      连接路径

      高级：直连地址提示

      节点 IP 继承当前节点的提示；助手端默认自动探测，可选择助手上报的网卡地址或手动填写。清空后仅使用自动探测，映射的目标 IP 保持原值。
