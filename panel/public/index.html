TCP 端口映射

下载并运行 Mac 或 Windows 免安装助手，将本机端口经服务器连接到指定 IP 的 TCP 服务。新连接优先局域网或 IPv6 加密直连，不可用时走 WSS 中转；已有连接保持原通道。

请选择运行助手的电脑版本。

Mac 首次运行说明

需要 macOS 12 或更新版本。解压 ZIP，双击文件夹内的 Start.command，在终端窗口粘贴配对码；也可在终端进入该文件夹运行 ./codex-cloud-forward。

如系统阻止打开，请先核对下载包的 SHA256，再按Apple 的首次打开说明，在“系统设置 → 隐私与安全性”中确认。本版尚未进行 Developer ID 签名及 Apple 公证。

目标从服务器所在网络访问。127.0.0.1 表示服务器自身，也可填写服务器可达的局域网或公网 IPv4 / IPv6。

助手只监听本机的 127.0.0.1。刷新、关闭网页或切换模式均保留映射。新版助手在检测到短暂断网后可于 30 秒内自动恢复，已有 TCP 连接需由原客户端重连。停止、退出原登录或授权过期后结束恢复；网页服务重启后需重新配对。
